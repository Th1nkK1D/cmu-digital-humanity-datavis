# Data Visualization: how we perceive and communicate with the surrounded world

Slides for **CMU Digital Humanity 2026**, by Withee Poositasai (Lookkid).

Built with [Slidev](https://sli.dev) and the
[tahta](https://github.com/zcag/tahta) theme. The deck lives in `slides.md`.

```bash
pnpm install
pnpm dev      # serve + open
pnpm build    # static build
pnpm export   # PDF
```
